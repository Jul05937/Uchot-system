# Система учёта пассажиров и поездок

## О проекте

Информационной системы для учёта пассажиров и их поездок
в транспортной компании. Система хранит информацию о пассажирах,
проданных билетах и доступных поездках.

**Практическая польза:**
- ведение учёта истории поездок пассажира(?);
- сокращение времени на оформление и поиск маршрутов, мест, билетов;
- помощь в отчётности по проданным местам;
- возможность пассажиру самостоятельно выбрать рейс и место,
  оформить билет или возврат.

## Пользователи

| Роль | Возможности |
|------|-------------|
| **Пассажир** | Просмотр доступных рейсов и мест, бронирование и покупка билетов, оформление возврата |
| **Кассир** | Просмотр рейсов и пассажиров, оформление билетов и возвратов, регистрация новых пассажиров, проверка наличия мест, добавление других кассиров |

## Основные функции

- Регистрация пассажира
- Просмотр списка доступных рейсов
- Поиск рейса (по пункту назначения, дате, пункту выезда)
- Бронирование места
- Оформление билета
- Возврат билета
- Вывод списка свободных мест

## Архитектура

Проект построен на **трёхуровневой архитектуре**:

1. **Presentation Layer** — интерфейс для пассажира и рабочее место кассира
2. **Business Logic Layer** — проверка доступности мест, правила возврата, бронирование
3. **Data Layer** — база данных: таблицы Пассажиров, Рейсов, Билетов, Поездок(?), Маршрутов

**Средства реализации:** Python 3, Git, GitHub, PlantUML.
