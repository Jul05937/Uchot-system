# Система учёта поездок и пассажиров

## О проекте

Учебный проект информационной системы для учёта поездок и пассажиров.
Автоматизирует ведение расписания рейсов, регистрацию пассажиров,
оформление и возврат билетов.

## Пользователи

| Роль | Возможности |
|------|-------------|
| Кассир | Добавление кассиров, регистрация пассажиров, поиск рейсов, оформление и возврат билетов |
| Пассажир | Вход в систему, просмотр рейсов, бронирование билетов |

## Запуск

```bash
python src/main.py
```
